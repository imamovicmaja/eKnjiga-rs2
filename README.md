# eKnjiga

## / eKnjiga - Backend API

Pokretanje API-ja putem Dockera:

`docker compose up --build`

## /eKnjigaDesktopUI - Desktop App

Komanda za pokretanje na windows:

`flutter run -d windows`

ili

`flutter run`

pa odabrati željeni uređaj.

## /eknjiga_mobile_app - Mobile App

Komanda za pokretanje:

`flutter run` 

Zatim odabrati željeni uređaj ili pokreni direktno pomoću:

`flutter run -d <device_id>`
